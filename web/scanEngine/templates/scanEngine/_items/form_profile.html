Profile Options Guide

Options are organized by category:

  • Speed options: Control scan speed and intensity (rate_limit, delay, timeout, retries)
  • Evasion options: Stealth and evasion techniques (fragment, tcp_syn_stealth, proxy, etc.)
  • General options: Global scan approach (active, passive, and their variants)
  • Network & Feature options: Network-specific settings and feature activation (ports, headless, nuclei, etc.)

Tips:

  • Click "Load Default Options Template" to see all available options with descriptions
  • Remove options you don't need or modify their values
  • Options are grouped by category with comments explaining each option
  • Use enforce: true to make this profile override conflicting options
