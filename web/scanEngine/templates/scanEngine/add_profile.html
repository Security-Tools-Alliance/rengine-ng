    Profiles

    Profiles define configuration options for scans. They allow you to customize scan behavior, speed, evasion techniques, and feature activation.
    YAML configuration allows you to define option overrides that will be applied during scan execution.

    Profile Configuration Help

    Profiles can be categorized as: speed (scan speed and intensity), evasion (stealth and evasion techniques), general (global scan approach), or network (network-specific options).
    The enforce option determines whether the profile should enforce its options even if they conflict with other settings.
    Learn more about profiles in the documentation
